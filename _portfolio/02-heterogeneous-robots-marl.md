Signed Type Encoding lets a single neural policy learn robot-specific roles, and curriculum learning carries those skills into multi-step sequential and multi-robot collaborative tasks. Built and trained in Unity ML-Agents with PPO.

Follow-up work (IEEE ICTAI 2026) adds a priority-aware grid sensor that scales coordination to ten robot types and generalizes to unseen task sequences.

**Role:** first author; designed and ran all experiments. **Paper:** [IJMERR 2026](https://www.ijmerr.com/2026/IJMERR-V15N3-331.pdf)
